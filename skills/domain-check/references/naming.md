# Naming patterns and how to judge a hit

## Patterns for the first batch

Each pattern SHOULD give a few names. Mix them in one batch.

| Pattern        | How                                     | Example for a coffee cart |
| -------------- | --------------------------------------- | ------------------------- |
| Plain pair     | two short words about the product       | Bean Cart                 |
| Place or local | a local word, plant, animal or landmark | Wattle Brew               |
| Coined         | a new word from parts of real ones      | Brewlark                  |
| Metaphor       | a thing that stands for the feeling     | Morning Ember             |
| Action         | a verb the customer does                | Sip Stop                  |
| Short and odd  | a real word from outside the field      | Kettle Fox                |

- **Coined names** clear the registers best. Plain pairs clear them least.
- **Generic words** such as "Coffee Shop" can't get a trade mark. Drop them.
- **Other languages** check that the name isn't rude in any language
  of the market. Say which ones were checked.

## Filters before the run

- **Say it once** a person who hears the name SHOULD spell it right.
- **No look-alikes** drop a name one letter off a known brand.
- **No geography claim** a city name alone in the brand is weak as a mark.

## Judging a risky row

- **`.com` taken** fine for an Australian business when `.com.au` and `.au`
  are free. Check `.com` in a browser: a parked page MAY be for sale.
- **`.au` taken, `.com.au` free** the holder of `.au` often owns the same
  brand. Open the site before picking.
- **Business name match** a business name gives no rights to the words.
  Still, a same-name business in the same field and state confuses buyers.
- **Live marks contain the words** open each one. A mark blocks the name only
  in its classes and close ones. Class 43 for cafes doesn't block class 9 for
  an app.
- **Same field, same words** treat as taken, even when the mark is pending.
