# Naming patterns and how to judge a hit

## Patterns for the first batch

Each pattern SHOULD give a few names. The agent SHOULD mix them in one batch:

| Pattern        | How                                     | Example for a coffee cart |
| -------------- | --------------------------------------- | ------------------------- |
| Plain pair     | two short words about the product       | Bean Cart                 |
| Place or local | a local word, plant, animal or landmark | Wattle Brew               |
| Coined         | a new word from parts of real ones      | Brewlark                  |
| Metaphor       | a thing that stands for the feeling     | Morning Ember             |
| Action         | a verb the customer does                | Sip Stop                  |
| Short and odd  | a real word from outside the field      | Kettle Fox                |

- **Coined names** clear the registers best and plain pairs least, so the
  batch SHOULD lean on coined names.
- **Generic words** such as "Coffee Shop" can't get a trade mark. The agent
  MUST drop them.
- **Other languages** the agent MUST check that the name isn't rude in any
  language of the market, and SHOULD say which ones it checked.

## Filters before the run

- **Say it once** a person who hears the name SHOULD spell it right.
- **No look-alikes** the agent MUST drop a name one letter off a known brand.
- **No geography claim** a city name alone in the brand is weak as a mark, so
  the agent SHOULD NOT rely on one.

## Judging a risky row

- **`.com` taken** this MAY pass for an Australian business when `.com.au`
  and `.au` are free. The agent SHOULD check `.com` in a browser: a parked
  page MAY be for sale.
- **`.au` taken, `.com.au` free** the holder of `.au` often owns the same
  brand. The agent MUST open the site before picking.
- **Business name match** a business name gives no rights to the words.
  Still, a same-name business in the same field and state confuses buyers,
  so the answer SHOULD flag it.
- **Live marks contain the words** the agent MUST open each one. A mark
  blocks the name only in its classes and close ones. Class 43 for cafes
  doesn't block class 9 for an app.
- **Same field, same words** the agent MUST treat it as taken, even when the
  mark is pending.

## Trade mark classes people ask about

The agent SHOULD match each mark to these classes:

| Class | Covers                                       |
| ----- | -------------------------------------------- |
| 9     | software, apps                               |
| 35    | retail, advertising, business services       |
| 41    | education, events, entertainment             |
| 42    | software as a service, design, tech services |
| 43    | cafes, restaurants, accommodation            |

The agent MAY look up the full list at
[IP Australia](https://www.ipaustralia.gov.au/trade-marks/what-are-trade-marks/what-are-classes-of-goods-and-services).
