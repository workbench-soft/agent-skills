# What language to write in

The answer MUST use two languages, kept separate:

- **Report language**: the four parts of the report, text that only the user
  reads. It MUST be taken from `LANGUAGE.md` next to `SKILL.md`. With no such
  file, or a file naming no language, it MUST be English.
- **English**: each comment meant for the PR MUST be written in English, since
  the full team reads a PR.

For the report, this MUST replace the `writing-style` rule to "answer in the
language the user wrote in". A one-line ask like "review PR 42" makes no
language choice by itself, so `LANGUAGE.md` still wins. Only an explicit ask in
this conversation, like "write it in English" or "in Russian please", MAY
change it, and it wins quietly, with no remark about it.

The examples in these files are in English. Their shape MUST be copied, with
the agent's own words in the report language. The headings MUST get translated
as well: **Comments**, **Explanations**, **Who hits it**, **Now**, **Comes
out**, **Costs**, and the headings of the findings table.
