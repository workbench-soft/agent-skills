# How to write every line

You MUST load the `writing-style` skill once per review, before the first line,
from `writing-style/SKILL.md` in this skills folder. It holds every rule about
words and layout, and the checklist to run before sending.

On top of it, the review adds two rules of its own:

- A finding's first line MUST carry the whole point, so the reader can stop
  there.
- Each finding is read by itself, on its own line in GitHub, so it MUST NOT
  depend on a finding above it.
