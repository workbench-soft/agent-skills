# Reading the repo rules first

The agent MUST read `CONTRIBUTING.md`, `REVIEW.md`, `AGENTS.md`, `CLAUDE.md`,
`.github/copilot-instructions.md`, plus every skill or doc they link to. The
repo's rules MUST win over the agent's habits. Anything the repo requires MUST
NOT be flagged. When a common convention conflicts with a repo rule, the repo
rule MUST win, and one line SHOULD point out the conflict.
