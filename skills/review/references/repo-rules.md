# Reading the repo rules first

You MUST read `CONTRIBUTING.md`, `REVIEW.md`, `AGENTS.md`, `CLAUDE.md`,
`.github/copilot-instructions.md`, plus every skill or doc they link to. The
repo's rules win over your habits. Anything the repo requires MUST NOT be
flagged. When a common convention conflicts with a repo rule, the repo rule
wins, and one line points out the conflict.
